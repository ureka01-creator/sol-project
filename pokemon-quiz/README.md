# 포켓몬 스피드 도감 퀴즈

한솔이용 포켓몬 1세대(관동도감 001~151) 4지선다 스피드 퀴즈.

## 게임 규칙
- 시작 화면에서 5 / 10 / 20 / 30문제 선택
- 포켓몬 이미지가 완전히 로드된 뒤 3초 카운트다운 시작
- 3초 안에 4개의 보기 중 이름 선택
- 시간 내 선택하지 않으면 자동 오답 처리
- 세션 내 같은 포켓몬 중복 출제 없음
- 정답 수, 연속 정답, 최종 정답률 표시
- iPhone / iPad / PC 반응형 UI
- 저작권 음악 대신 Web Audio로 간단한 효과음만 사용

## 이미지
포켓몬 이미지는 PokeAPI sprites 저장소의 official-artwork 리소스를 원격으로 사용하며, 로드 실패 시 기본 sprite로 자동 대체합니다.

## 실행
정적 웹앱이므로 `index.html`을 웹 서버에서 열면 됩니다.
