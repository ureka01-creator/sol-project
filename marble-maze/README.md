# 구슬 미로 v0.1.0

상자를 기울여 구슬을 굴리는 영상을 참고한 HTML Canvas 게임.

## 실행
`index.html`을 브라우저로 열면 됩니다. 빌드나 외부 의존성이 없습니다. 휴대폰 기울기 조작은 HTTPS에서 실행하고 사용자 버튼으로 센서 권한을 허용해야 합니다.

## 조작
- 모바일: 아래 원형 패드를 드래그하거나 `기울여서 조작` 선택
- PC: 방향키
- 목표: 오른쪽 아래 초록색 도착 지점 진입
- `처음부터` 또는 성공 화면의 `한 번 더`로 초기화

## 구현
고정 120Hz 물리 업데이트, 관성·마찰·벽 반사, 원-사각형 충돌, 화면 회전 대응 및 센서 기준 자세 보정, 센서 불가 시 터치 대체 조작, 탭 비활성 시 정지.

## 검증
JavaScript 문법 검사와 Node VM에서 벽 관통 방지, 전체 경로 통과, 도착 판정, 재시작 검증 통과. 실제 iPhone/iPad 기울기 및 브라우저 화면 검증은 아직 하지 않았습니다.

## 범위
첫 버전은 미로 1개입니다. 영상의 여러 상자와 입체 구조를 모두 재현한 버전은 아닙니다. 기존 게임과 독립된 marble-maze 폴더입니다.
